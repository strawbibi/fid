# Ube & Alfajor Café

A fictitious coffee shop website blending Filipino ube-based drinks and desserts with Argentine alfajores.

## About This Project

This site was created as a class project to demonstrate HTML and CSS skills, including:

- 6 linked HTML pages (Home, Menu, Our Story, Gallery, Catering, Contact)
- An external stylesheet (`style.css`) with no inline or embedded styles
- A custom Google Font (Fredoka & Nunito)
- CSS layout properties including `position` and `display`
- A CSS pseudo-class (`:hover`) on navigation links, cards, and buttons
- Ordered and unordered lists
- Semantic header tags (h1, h2, h3)
- Stock images throughout the site
- A footer with text navigation, copyright symbol, year, and designer credit
- A properly coded email hyperlink
- An external hyperlink that opens in a new window
- Special HTML characters (©, —, ·, and more)

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Home page with intro and mission |
| `menu.html` | Full menu of ube drinks, Filipino desserts, and Argentine sweets |
| `about.html` | The café's origin story |
| `gallery.html` | Photos from inside the café and community events |
| `catering.html` | Catering packages and booking process |
| `contact.html` | Contact info, hours, and location |
